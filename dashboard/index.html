Upload rules
  • Upload one file per sensor — six separate files below, not one combined workbook.
  • Each file should contain only that sensor's own data (a single sheet/page), not multiple sensors combined — this keeps the computation simple and unambiguous.
  • Accepted formats: .xlsx (fully supported), or .xls / .csv (accepted and saved, see note below).
  • Uploading a file replaces the existing one for that sensor slot.
Coming soon: automatic checking that an uploaded file matches the expected column layout, and automatic .xls/.csv → .xlsx conversion. Today, .xlsx uploads go live immediately and must already match the existing template (see README); .xls/.csv uploads are saved to _pending_uploads/ for manual conversion.
